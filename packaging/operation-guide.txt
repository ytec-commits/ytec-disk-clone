Y-TEC Tsumugi Drive 操作ガイド（開発候補）
================================================

1. この版について
-----------------

この版は実機受入前の開発候補です。重要データ、業務端末、唯一のバックアップへ
使用しないでください。最初はNICを無効にした専用VMと合成ディスクで確認します。

2. Windows版の起動
------------------

1. ZIPを通常フォルダーへ展開します。ZIP内から直接起動しません。
2. ytec-tsumugi-drive.exeを起動します。
3. 標準権限ではディスク診断、選択内容、ADK環境だけを読み取り専用で確認できます。
4. VSSイメージ作成や媒体作成が必要なときだけ、アプリを閉じてから
   「管理者として実行」を手動で選びます。アプリは自動昇格しません。

3. ドライブをクローン
----------------------

1. コピー元と、消去してよいコピー先を選びます。
2. 容量、方式、モデル、シリアル末尾、Windowsディスク表示を確認します。
3. 対象情報の確認1/2と、画面に表示された対象固有語の入力2/2を行います。
4. Windows版はハッシュ付き予約ジョブを新規保存します。
5. Tsumugiのレスキューメディアで起動し、同じ対象が再識別された場合だけ
   オフラインクローンへ進みます。

コピー先の全内容は失われます。ディスク番号だけで判断しないでください。

4. イメージを作成
------------------

1. Windowsシステムディスクを選びます。
2. 同じ物理ディスク以外の固定ローカル保存先へ、新しい.dcimg名を指定します。
3. VSS、読取り、書込み、検証、Snapshot後始末の進捗を確認します。
4. 完全検証とSnapshot削除が成功した場合だけ完成名になります。

5. イメージを復元
------------------

1. 通常ファイルの.dcimgを選び、全体と全チャンクのSHA-256検証を待ちます。
2. 復元先候補の容量、セクター、元ディスクとの分離を確認します。
3. 2段階確認後、復元予約ジョブを新規保存します。
4. レスキューメディアで起動し、イメージと復元先を再確認して実行します。

復元先の全内容は失われます。破損、差替え、不一致は成功扱いにしません。

6. 起動を修復
--------------

クローンや復元を行わず、BCDの再構築だけに利用できます。

1. 「起動を修復」からレスキューメディア作成へ進みます。
2. 対象PCをレスキューメディアから起動します。
3. Windows領域、システム領域、UEFI/BIOSを確認します。
4. 読み取り専用プリフライトと対象固有語の入力後だけ、Microsoft署名を確認した
   BCDBootでブートファイルを再構築します。

BitLocker回避、Secure Boot回避、ライセンス認証回避は行いません。

7. レスキューISO / USB
----------------------

事前にMicrosoft公式Windows ADKとWinPE Add-onを導入してください。

1. 「レスキューメディア」で環境確認を実行します。
2. ISOまたはUSBと、2011 CA互換重視/2023 CA移行対応を選びます。
3. ISOは存在しないローカル絶対パスを指定します。
4. USBはMBR・単一パーティション・USB接続・非システムの候補だけ選べます。
5. 内容確認と対象固有語を確認し、管理者として作成します。
6. 完了したISOまたはUSBの検証結果を保存します。

Secure Boot起動可否はPCのファームウェア証明書と失効状態にも依存します。

8. 進捗と中止
--------------

画面には工程、読取り/書込み/検証済み容量、速度、経過時間、残り時間を表示します。
残り時間は十分な実測量がない間は表示しません。安全に中止できる工程だけ
中止できます。最終パーティション表確定など中止できない短い工程では待ちます。

9. ログ
-------

Windows版は実行ファイル横のlogsへ新しいUTF-8ログを保存します。
問い合わせにはログ、発生時刻、操作、画面のエラーコードを添えてください。
ディスクイメージ、BitLocker回復キー、製品キー、個人ファイルは送らないでください。
