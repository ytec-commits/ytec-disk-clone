Y-TEC Tsumugi Drive 0.2.0-dev 開発版
=================================

このパッケージにはY-TECが作成した実行ファイル、スクリプト、文書だけが
入っています。Microsoft Windows PE、WIM、ISO、CAB、ADKツールは
同梱していません。

Windows版:
  ytec-tsumugi-drive.exe

レスキューISOを作成する場合:
  1. Microsoft公式のWindows ADKとWinPE Add-onを利用者自身で導入します。
  2. ytec-tsumugi-drive.exeを開き、「レスキューメディア」を選びます。
  3. 読み取り専用の環境確認後、ISOの保存先と起動互換性を選びます。
  4. 実際のWIM構成とISO生成時だけ管理者権限が必要です。

レスキューUSBを作成する場合:
  1. Microsoft公式のWindows ADKとWinPE Add-onを利用者自身で導入します。
  2. 内容を消去してよいGPT/MBR・単一パーティションのUSBメモリを接続します。
  3. 画面に表示された物理ディスク番号、容量、シリアル末尾を確認します。
  4. 2段階確認後、選択USB全体だけをMBR・単一FAT32へ自動初期化します。
  5. ローカルADKの公式MakeWinPEMediaでUSBを作成します。
  6. 完了時はUSB上の全媒体ファイルがSHA-256で照合されます。

通常のディスク診断、作成内容確認ではUACを要求しません。UACを無効化したり、
Secure BootやMicrosoft署名検査を回避したりしないでください。

現在の制限:
  - USB直接作成は実装済みですが、物理USBでの破壊的VM/実機試験前です。
  - 製品クローン、復元、MBR→GPT、完成候補ISOは合成ディスクを使う
    最終VM回帰まで合格していますが、実機受入前です。
  - 通常モードはWindows/データ専用ディスク、縮小移行モードは基本NTFSの
    使用量と安全余白が収まる小容量先に対応します。縮小イメージ作成・復元は
    合成データ専用ディスクの最終VM回帰まで合格していますが、実機受入前です。
  - 実機試験前の開発版であり、重要データへ使用しないでください。

レスキューISOは利用者PCのローカルADKから生成され、クラウドへ送信しません。
生成したISO、WIM、ログはY-TECのリポジトリや配布ZIPへ自動コピーされません。

詳しい手順、安全上の注意、通信の有無は同梱文書を確認してください。
