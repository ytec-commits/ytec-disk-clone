# Windows版GUI進捗

## 2026-08-03 縮小移行・データ専用対応

- クローン、イメージ作成、復元へ`通常モード（完全複製）`と
  `縮小移行モード（小容量へ）`の共通選択を追加した
- Windows起動ディスクだけでなく、GPT/MBR基本ディスクのデータ専用ディスクも
  両モードのコピー元/イメージ元として表示する
- 通常モードは`.dcimg`、縮小移行は`.dcmig`ディレクトリ束を非上書きで作成する
- 縮小クローンは、コピー元/コピー先と異なる第三物理ディスクの未使用
  `.dcmig`名を必須にし、ジョブも同じ第三ディスクへ保存する
- 復元は`.dcimg`または`.dcmig`内の`manifest.dcmig`を読み取り専用で選び、
  全チャンクまたは全WIMの完全検証後だけ候補選択へ進む
- ジョブはv4 `transferMode=exact/shrink`。旧v2/v3は通常モードへ固定して読む
- データ専用イメージには「起動領域なし」と表示し、WinPE実行でもBCDBootを行わない
- 現行差分の通常/静的CRT/ASan各43/43、MSVC静的解析、全境界検査はPASS
- 4 GiB合成データ専用原本→2 GiB RAWのVSS作成・縮小復元VMもPASS。
  原本不変、ファイル一致、Snapshot残留0件、起動処理なしを確認

以下の2026-07-31記録は通常`.dcimg`中心の履歴であり、上記更新を打ち消しません。

## 2026-07-31時点

外部UIライブラリを追加せず、C++20とWin32 APIだけで
`ytec-tsumugi-drive.exe`の製品画面を追加しました。初期画面は説明用ページでは
なく、実ディスクを読み取り専用で非同期列挙するクローン選択画面です。

画面には次を用意しています。

- ドライブをクローン
- イメージを作成
- イメージを復元
- 起動を修復
- レスキューメディア
- ログ・診断
- コピー元／コピー先のモデル、容量、GPT/MBR、BusType、
  論理／物理セクター、パーティション構成、シリアル末尾
- 選択、安全確認、実行、完了の4段階表示
- 処理段階、処理量、転送速度、経過時間、推定残り時間の進捗枠
- コピー先のモデル、容量、シリアル末尾、全削除対象数を示す確認1/2
- コピー先固有の確認語が完全一致した場合だけ有効になる確認2/2
- 確認済みクローンジョブの正規UTF-8 JSON＋SHA-256生成と新規保存
- 現在のWindowsディスクを読み取り専用コピー元として表示する
  オンライン・イメージバックアップ画面
- 標準権限では物理ディスクを開く前に停止し、実行ボタンを無効化して
  自動UACを行わない権限境界
- 管理者実行時だけ、新規`.dcimg`保存先の確認後にバックグラウンドで
  製品VSSサービスを呼び、成功/失敗を画面へ返す接続
- 標準権限でADK/WinPE Add-on、Microsoft署名、検証済みバージョン、
  必須更新、`/bootex`を読み取り専用診断するレスキューメディア事前確認
- BIOS/UEFI基本構成、2023 CA、作成許可ゲートを表示しつつ、
  Secure Bootの実起動はVM・実機確認が必要だと明示する結果画面
- 「環境確認→形式・出力先→内容確認→作成」を現在位置付きで示す
  レスキューメディア4段階ウィザード
- ISO/USBと2011/2023 CAを明示選択し、ISOは新規ローカル`.iso`パス、
  USBは安全条件を満たす列挙候補だけを作成前確認へ進める画面
- ローカル通常ファイルの`.dcimg`を選択し、ヘッダー/サイズ境界、
  全体・全チャンクSHA-256、正規マニフェスト、パーティション表、
  復元領域の意味整合を読取り専用で完全検証する復元前画面
- 完全検証後、列挙済み情報だけで安定識別、元ディスク/システムディスク除外、
  読取り専用/リムーバブル/不明状態、形式、容量、論理セクターを確認する
  復元先候補欄
- 復元先情報の確認1/2と対象固有語の完全一致2/2を通った場合だけ、
  正規UTF-8 JSON＋SHA-256の復元予約ジョブを新規保存・読戻し検証する入口

推定残り時間は16MiB以上かつ3秒以上の観測が揃うまで「計算中」とし、
開始前、プリフライト、失敗時は不確かな時間を表示しません。

## 現在の安全境界

通常のWindows版GUIは次を行います。

- 標準権限でも可能な範囲だけを読み取り専用で列挙する
- 現在のWindowsディスクを既定のコピー元にする
- 現在のWindowsディスク、同一ディスク、読み取り専用、
  読み取り専用状態不明、コピー元より小さいディスクをコピー先として拒否する
- クローン選択が安全な場合だけ二段階確認へ進み、ディスクには書き込まず、
  WinPE引継ぎ用ジョブJSONだけを作成する
- ジョブJSONはローカル絶対`.json`パスへ`CREATE_NEW`で作成し、既存ファイルを
  上書きせず、flush、全バイト読戻し、payload SHA-256再検証後だけ完了とする
- オンラインイメージは現在のWindowsシステムディスクだけを許可し、
  再列挙した安定識別、GPT/MBR、NTFS/FAT32ブート情報、BitLocker署名、
  VSS Volume対応、保存先物理ディスクを実行直前に検査する
- 保存先確認後、書込み開始前に公式Windows Update Agentの読取り専用
  `RebootRequired`を照会する。再起動保留あり、またはAPI判定不能なら
  最終確認を警告色にし、既定「いいえ」のまま再起動/確認を推奨する
- `.dcimg.partial`を全件読み戻した後もすぐ完成名にせず、VSSの
  `BackupComplete`とSnapshot set削除が成功した後だけ非上書きで確定する
- 復元イメージの選択と完全検証、復元先候補の読み取り専用基礎確認、
  二段階確認、復元予約ジョブ保存だけを有効にする。候補が合格しても
  復元実行は無効で、復元先ディスクは未オープンのままにする
- Windows側の起動修復誘導は、製品サービスへの接続が完成するまで
  実行ボタンを無効にする
- レスキューメディアは読み取り専用診断と生成直前の選択/要約を有効にする。
  ISOは手動で管理者起動した場合だけ製品生成サービスへ進み、自動UACは行わない。
  USBは非システム、USB接続、取り外し可能、オンライン、非読み取り専用、
  既知パーティション形式、安定識別に加え、実行直前の再列挙、一意一致、
  ディスク番号不変、状態変化なし、二段階確認まで再検証する。管理者として
  手動起動した場合だけローカルADKの公式UFD処理へ同じ対象を渡し、
  完了後も再識別して全媒体ファイルの長さ/SHA-256を照合する。物理USBでの
  破壊的実測前なので利用可能とは扱わない

この画面を追加したことは、一般利用者向けの書込み機能が有効になったことを
意味しません。作成したジョブはWinPEでハッシュと安定識別を再検証できますが、
実行時の追加検査とWinPEクローン/復元サービス、キャンセル境界は
接続済みですが、自動再起動、Windowsへの結果復帰、製品経路の破壊的VM試験は
まだ完了していません。

## 実画面確認

標準権限、1280x720で次を確認しました。

2026-08-01にはLINE Seed JP Regular/Boldをプロセス内限定で読み込む版を、
標準権限で実測しました。ログの`UIフォント LINE Seed JP 読込み成功`、
1280x720相当の全6画面、最小追跡幅での966x713表示、コピー元/コピー先の
ドロップダウン展開を確認しました。クローンの2つのコンボは各カード内へ収め、
レスキューメディアの2つのコンボと保存先/参照ボタンはカード右端へ18pxの
余白を保持する共通矩形計算と単体テストを追加しています。

- 3台の実ディスクが読み取り専用で列挙される
- ディスク情報とパーティションバーに文字切れ、重なりがない
- 既定でWindowsディスクから十分な容量の非システムディスクが選ばれる
- 小容量ディスクへ変更すると理由を表示し、「安全確認へ」が無効になる
- 起動修復画面へ移動できる
- イメージ作成画面で現在のWindowsディスクだけが表示され、説明文と
  コピー元コンボに重なりや横はみ出しがない
- 標準権限では「保存先を選ぶ」が無効で、自動UACや保存画面が開かない
- レスキューメディア画面で「作成準備を確認」が標準権限でも有効で、
  ADK `10.1.26100.2454`、BIOS/UEFI基本構成、2023 CA用`/bootex`、
  必須更新の確認済みと作成許可を表示する
- 読み取り専用診断時にUAC、WIM/ISO/USB生成が発生せず、
  成功時は未使用ADK候補の欠落診断を混在させない
- 診断結果をカード用の短い表示と詳細ダイアログへ分け、
  1280x720で文字の重なりと下端のはみ出しがない
- 診断合格後に4段階表示が「形式・出力先」へ進み、ISO/USB、
  2011/2023 CA、ISO保存先またはUSB候補のコントロールが重ならない
- USBへ切り替えるとISO欄が消え、全消去警告とUSB候補欄へ変わる。
  安全条件を満たすUSBがない場合は確認ボタンが無効のままで、
  USBや物理ディスクを開かない
- イメージ復元画面から旧マニフェストの既存合成証跡を選ぶと、
  現行形式として受理せず、マニフェストヘッダー異常を表示して停止する
- 現行形式の合成`.dcimg`は読取り専用完全検証に合格し、コピー元、
  容量、MBR/Legacy BIOS、Windows版、パーティション/チャンク数を表示する
- 合格画面と結果カードの両方に、復元先を開いておらず
  復元実行が無効であることを表示し、1280x720で文字の重なりがない
- 完全検証後に固定ディスク候補が自動選択され、容量・論理セクター・
  基本状態の確認済みと「復元実行: 無効」が同時に表示される
- 現在動作中のWindowsディスクへ選択を変えると、書込みやUACを行わず
  「復元先にできません」の警告へ切り替わる
- 正常候補では「復元ジョブの確認へ」が有効になり、動作中Windowsディスクでは
  無効になる。破壊的警告は既定「いいえ」で、実画面確認では先へ進めていない
- 復元予約ジョブv3（v2手動互換）へ検証済み`.dcimg`のファイル長と全体SHA-256を保持し、
  WinPEで別パスを再選択しても同一イメージだけを受理できる
- Tabキーで次のナビゲーション項目へ移動できる
- 確認1/2がコピー先のモデル、容量、シリアル末尾、全削除数を表示する
- 誤った確認語では作成ボタンが無効で、完全一致時だけ有効になる
- 同じ確認画面で既定OFFの一回限り自動実行を明示選択でき、選択値が
  `executionMode`としてpayload SHA-256へ含まれる。未選択は手動確認のまま
- 保存画面から742バイトの一時ジョブを新規作成し、GUIの読戻し検証が成功する
- 同じ一時ジョブをWinPEAppの`--job-preflight`へ渡し、SHA-256と
  コピー元／コピー先の安定識別再解決が成功し、`executionEnabled=false`となる
- 確認後、一時ジョブだけを削除し、物理ディスク書込みを行っていない
