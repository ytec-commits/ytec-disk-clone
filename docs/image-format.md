# イメージ形式

Phase 0では形式を実装しませんでしたが、現在は通常モードの`.dcimg` v1と、
縮小移行モードの`.dcmig` v1を実装しています。

## 通常モード `.dcimg`

`.dcimg`は単一ファイルです。正規バックアップマニフェスト、MBR/GPT
パーティション表スナップショット、Zstandard/非圧縮ストリーム作成、
全件読戻し検証、合成復元まで実装しています。コピー元ディスクの総容量を
復元境界として保持するため、復元先は原則として同容量以上が必要です。

固定レイアウト、確定順序、互換性、安全側の拒否条件は
[`.dcimg` v1形式基盤](image-format-v1.md)を正本として扱います。

公式Zstandard v1.5.7をBSD-3-Clause条件で静的リンクし、プロファイル1を
実装しています。level 3、辞書なし、内容サイズとフレームチェックサムありの
単一フレームに固定し、圧縮後が小さくならないチャンクだけ非圧縮で保存します。
未知プロファイル、辞書、連結/末尾フレーム、内容サイズ不明、破損は拒否します。

## 縮小移行モード `.dcmig`

`.dcmig`は末尾が`.dcmig`のディレクトリ束です。内部の固定名
`manifest.dcmig`が、コピー元の安定識別、GPT/MBR、Windows/データ専用の役割、
NTFS使用量、クラスター寸法、各WIM名・長さ・SHA-256を正規バイナリ形式で
保持します。各NTFS内容は、VSS Snapshotの正確なVolume GUIDパスから
Microsoft DISMで別々のWIMへ取得します。

作成時は未使用の一時ディレクトリだけへ書き、全WIMとマニフェストを再検証し、
VSSの完了とSnapshot set削除後だけ完成名へ確定します。復元時は
`.dcmig`ディレクトリ、マニフェスト、全WIMを置換できない状態で読取り専用ロックし、
宣言外項目、reparse、長さ/SHA-256不一致をコピー先書込み前に拒否します。
コピー先の最小容量、対応構成、余白計算は
[縮小移行モード](shrink-migration-mode.md)を参照してください。
