## 現時点のリリース停止条件

- 縮小移行のコード、43件の通常/静的CRT/ASan、静的解析、全境界検査、
  4 GiBデータ専用原本→2 GiB RAWの製品VMは合格。残る停止条件は代表実機受入
- Windows GUIはクローンジョブ、オンラインイメージ作成、
  復元イメージの読み取り専用完全検証/復元先候補基礎確認/二段階確認/
  予約ジョブ、メディアの事前診断を接続済みだが、
  メディア生成、復元進捗/ETA/キャンセルの実VM測定は未完了。
  現在のWindowsでは公式WUAの再起動保留を読取り専用判定して警告し、
  WinPE上のオフライン対象は安全と推定せず警告`unknown`を維持する
- レスキューISOのelevated生成サービスと実行直前再検査は接続済みで、
  2026-08-01午前版の完成ISO/manifest発行と6条件起動を確認済み。
  その後に追加したLINE Seed JP/OFLを含む再生成と成功時後始末を残す。USBは実行直前/直後再列挙、二段階確認、
  対象限定公式UFD処理、全媒体ファイルSHA-256まで接続済みだが、
  物理USBへの破壊的VM/実機試験は未実施
- WinPE GUI、ローカルADK日本語フォント、埋込みLINE Seed JP、OFL本文を含む
  最新ISOの生成とBIOS/UEFI/Secure Boot起動回帰が未実施
- 仕様で必須の実機マトリクスは、利用者方針どおり最終段階まで未実施
- Visual Studio/MSVCの使用資格、コード署名、利用規約等の公開判断は人間確認

## UAC一括作業へ送る項目

- 4 GiB合成データ専用原本から`.dcmig`を作り、2 GiB RAWへ復元して、原本/
  sentinel不変、復元内容一致、BCDBoot未実行、Snapshot 0件、VM環境復元を確認
- 更新したWinPE CLI/GUIとローカルADK日本語フォントをWIMへ統合して
  ISOを再生成
- 更新ISO上で復元ジョブの実行直前安全判定を専用の合成ディスクだけで確認
- 更新ISO上でGPT/MBRクローン予約ジョブの空RAW、固定ディスク、既知BusType、
  MBR署名衝突検査、二段階確認を専用の合成ディスクだけで確認
- 製品クローンの修正済み自動検証ランナーを最新ISOへ収録し、
  GPT/MBRのPASSマーカーとコピー先単独起動を再確認
- 専用復元先へ製品`.dcimg`復元を完走し、成功時online復帰、区画再列挙、
  全データ読戻し、起動可否を確認
- 完全検証中/書込み前のキャンセルと、データ復元中の安全キャンセルを確認し、
  途中失敗/中止時に対象がofflineのまま保護されることを確認
- Legacy BIOS、UEFI、Secure Boot 2011 CA/2023 CAで最新GUI媒体の
  自動起動、日本語表示、ファイル選択を確認
- USB物理媒体への作成、BIOS/UEFI/Secure Boot起動試験
- コード署名を採用する場合の証明書操作

それ以外の形式、UIロジック、モック、静的解析、配布物監査は非昇格で先行します。
