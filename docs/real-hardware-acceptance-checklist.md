# 実機受入チェックリスト

更新日: 2026-08-01

この文書は、VMと自動試験が完了した後に利用者が行う最終実機試験の台帳です。
Y-TEC Tsumugi Driveを一般利用可能と判定するためのチェックであり、
開発途中のISOや、重要データを持つ実機では実行しません。

## 開始ゲート

- [ ] Codexが「実機候補版」と明示したポータブルZIP、ISO、manifestを使用する
- [ ] ZIP、ISO、収録EXE、manifestのSHA-256を記録し、開発側の値と一致する
- [ ] 試験対象は再作成可能なWindowsと合成データだけで、重要データを置かない
- [ ] コピー元とは別に復旧媒体と既知正常バックアップを用意する
- [ ] コピー先は全消去してよい専用品とし、モデル、容量、シリアル末尾を記録する
- [ ] 試験に不要な内蔵/外付けディスク、USBメモリ、メモリーカードを外す
- [ ] AC電源を接続し、スリープ、休止、Windows Update再起動を止める
- [ ] BitLocker回復キーを試験記録へ転記せず、安全な既存保管先だけで管理する
- [ ] 各破壊試験の直前に、画面のコピー元/コピー先と実物ラベルを指差し照合する

どれか1つでも満たせない場合は開始しません。ディスク番号だけでは照合せず、
モデル、容量、BusType、シリアル末尾、パーティション方式を組み合わせます。

## 試験記録の共通項目

各ケースで次を残します。完全シリアル、ユーザー名、回復キー、個人ファイル名は
記録しません。

- ケースID、日時、担当者
- PC機種、Windows 10/11とビルド、BIOS/UEFI、Secure Boot状態
- コピー元/コピー先の接続方式、媒体種別、公称容量、論理/物理セクター
- コピー元/コピー先のモデルとシリアル末尾
- 使用したZIP/ISO/EXEのSHA-256
- 操作開始前、確認1/2、確認2/2、完了/失敗画面
- 所要時間、平均速度、キャンセル可否表示、終了コードまたはエラー文
- コピー元を外した起動結果と、後述の起動受入結果
- アプリログ、Windowsイベントログ、必要な画面写真

## 機能マトリクス

同じ試験を無理に兼用せず、各行を個別に合否判定します。

| ID | ケース | 事前条件 | 合格条件 | 結果 |
|---|---|---|---|---|
| HW-GPT-01 | SATA SSD→同容量SATA SSD、GPT/UEFI | Windows 10または11、512/512e | 完走、読戻し合格、コピー元なしで起動 | 未実施 |
| HW-GPT-02 | NVMe SSD→大容量NVMe SSD、GPT/UEFI | Windows 11、512/512e、Secure Boot有効 | 完走、容量差を安全に処理、コピー元なしで起動 | 未実施 |
| HW-MBR-01 | SATA HDD→大容量SATA SSD、MBR/Legacy BIOS | Windows 10 x64、Active区画が一意 | 完走、コピー元なしでLegacy BIOS起動 | 未実施 |
| HW-USB-01 | 内蔵コピー元→USBケース内コピー先 | 対応SATA/NVMeケース、コピー先専用 | 対象を正しく再識別し完走、内蔵接続へ戻して起動 | 未実施 |
| HW-M2G-01 | MBR→GPT | 製品入口とWinRE処理の実装完了後だけ | 検証、変換、BCDBoot、WinRE確認、UEFI起動 | 保留 |
| HW-IMG-01 | VSSイメージ作成→別ディスク復元 | 保存先と復元先を別媒体にする | 自動検証合格、復元完走、コピー元なしで起動 | 未実施 |
| HW-REP-01 | UEFI/GPTの起動修復のみ | 破損させてよいクローン媒体 | BCD破損で起動失敗後、修復だけでログオン到達 | 未実施 |
| HW-REP-02 | BIOS/MBRの起動修復のみ | 破損させてよいクローン媒体 | BCD破損で起動失敗後、修復だけでログオン到達 | 未実施 |

4Kn→4Knは専用実機検証と明示的な有効化が終わるまで書込み禁止です。
512系↔4Knは初版対象外です。

## 安全拒否マトリクス

拒否試験は「最初の書込み前に停止」が合格条件です。重要なシステムディスクを
わざと危険状態にせず、再作成可能な試験媒体だけを使います。

| ID | ケース | 合格条件 | 結果 |
|---|---|---|---|
| SAFE-01 | BitLocker暗号化率が0%でないコピー元 | 完全復号を要求し、開始不可 | 未実施 |
| SAFE-02 | 動的ディスク/LDMまたはStorage Spaces | 対象外として開始不可 | 未実施 |
| SAFE-03 | コピー先が小容量 | 開始不可、警告だけで続行しない | 未実施 |
| SAFE-04 | 論理セクター不一致または4Kn書込み | 開始不可 | 未実施 |
| SAFE-05 | 確認1/2の対象変更またはディスク番号入替り | 再識別不一致で開始不可 | 未実施 |
| SAFE-06 | 確認2/2の誤入力 | 実行ボタンが有効にならない | 未実施 |
| SAFE-07 | 1ビット破損した`.dcimg` | コピー先を変更せず拒否 | 未実施 |
| SAFE-08 | コピー元とコピー先が同一 | 開始不可 | 未実施 |
| SAFE-09 | システムディスクをコピー先に選択 | 候補外または開始不可 | 未実施 |

## 高リスク障害試験

次は専用の犠牲媒体、復旧手順、個別Go/No-Goレビューを用意するまで実行しません。
USBを抜く、PCの電源コードを抜く、正常なディスクを故障させる、といった
場当たり的な方法は禁止します。

| ID | ケース | 安全な実施条件 | 結果 |
|---|---|---|---|
| FAULT-01 | 読取りエラー | 既知故障の犠牲媒体または承認済み故障注入装置 | 保留 |
| FAULT-02 | 電源断後の未完了判定 | 犠牲コピー先、制御可能な電源断、復旧計画、事前承認 | 保留 |
| FAULT-03 | 長時間処理中のキャンセル | 中断可能表示中だけ実行し、コピー元不変を確認 | 未実施 |

## 起動受入

クローン/復元/変換ごとに、コピー元を物理的に外してから確認します。

- [ ] 指定したUEFIまたはLegacy BIOS方式で起動する
- [ ] Secure Boot対象ケースではSecure Boot有効のまま起動する
- [ ] Windowsログオンまで到達する
- [ ] システムボリュームとドライブ文字が期待どおりである
- [ ] コピー元とコピー先を再接続してもディスク署名/GUID衝突がない
- [ ] イベントビューアーに重大なDisk、Ntfs、volmgrエラーがない
- [ ] 管理者コマンドの`chkdsk /scan`が重大エラーを返さない
- [ ] `reagentc /info`でWinRE状態と場所を記録する
- [ ] ディスクの管理でパーティション順、種類、容量を事前記録と比較する
- [ ] Windows Update、再起動、通常シャットダウンを各1回完了する

## レスキューメディアと画面

- [ ] 2011 CA互換ISO/USBをLegacy BIOSで起動する
- [ ] 2011 CA互換ISO/USBをUEFI/Secure Boot有効で起動する
- [ ] 2023 CA ISO/USBを対応UEFI/Secure Boot有効機で起動する
- [ ] 1280x720、100%でLINE Seed JP、日本語、ボタン、コンボ枠に重なりがない
- [ ] 125%と150%で文字切れ、横はみ出し、クリック不能がない
- [ ] コピー元/コピー先/媒体プロファイルのドロップダウン展開がカード内に収まる
- [ ] Tab/Shift+Tab、Space/Enterで主要操作ができる
- [ ] 高コントラストで選択、警告、無効状態を区別できる
- [ ] ファイル選択ダイアログと日本語パスが動作する

## 判定

- 1件でも「失敗」「未確認」「証跡不足」があれば、その構成は合格にしない
- 失敗後は同じ媒体へ再実行せず、ディスク状態とログを読取り専用で保存する
- コピー元に変化が疑われた場合はプロジェクト全体をリリース停止にする
- 全必須ケースの合格、配布物監査、法務/署名判断が揃うまで一般公開しない
